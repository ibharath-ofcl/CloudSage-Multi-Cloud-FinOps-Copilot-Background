# CloudSage Evidence Grounding and Anti-Hallucination Framework

## 1. The Anti-Hallucination Guarantee

Financial decision-makers require 100% verifiable data. Generative AI models are inherently prone to hallucinations when asked to calculate numbers or recall dates.

CloudSage completely prevents hallucinations through **Database-First Evidence Grounding**:
1. No dollar amount or resource count is generated by the LLM from memory or guesswork.
2. All figures cited in assistant responses are calculated by PostgreSQL/SQLAlchemy prior to prompt synthesis.
3. Every response references explicit database entities via structured **Evidence Citations**.
4. When underlying database records are absent or empty, the system explicitly reports data unavailability rather than fabricating plausible answers.

---

## 2. Structure of an Evidence Citation

Every retrieved query result produces verifiable citation items adhering to `EvidenceCitationSchema`:

```python
class EvidenceCitationSchema(BaseModel):
    source_table: str      # e.g., "billing_records", "waste_detections", "recommendations"
    record_id: str         # Primary key UUID or resource ARN
    description: str       # Human-readable factual summary
    metric_value: str      # Exact monetary cost or quantified impact
    confidence: float      # Certainty score (1.0 for database verified rows)
```

## 3. Grounded Response Layout

Assistant responses follow a rigorous four-part layout designed for executive clarity and financial auditability:

1. **Executive Summary**: Direct 1-2 sentence answer providing primary metrics and totals.
2. **Detailed Breakdown**: Granular distribution by provider, service, category, or dimension.
3. **Evidence & Citations**: Explicit bulleted list linking the findings back to underlying database tables and record IDs.
4. **Advisory Next Steps**: Non-destructive, human-in-the-loop recommendations to realize savings or investigate anomalies.
